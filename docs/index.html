O que é uma API?

API significa Application Programming Interface: interface de programação de aplicações.

Uma API é uma interface que define as operações e as regras pelas quais um software pode acessar funcionalidades ou trocar dados com outro. Ela estabelece como fazer uma solicitação e qual resposta esperar.

Nesta aula, usamos uma API web: o React envia requisições HTTP aos endpoints do Express, e o servidor responde com um status HTTP e, normalmente, dados em JSON.

Pense no atendimento de um restaurante.

Você faz o pedidoA interface envia uma requisição.
A cozinha preparaO servidor processa o pedido.
O atendimento entregaA API devolve a resposta.

Endpoint e método HTTP

Endpoint é um endereço da API usado para acessar um recurso, como /api/users. O método HTTP indica a ação que será realizada nesse endereço.

GET /api/usersConsultar a lista
POST /api/usersCriar um usuário
PUT /api/users/:idAtualizar um usuário
DELETE /api/users/:idExcluir um usuário

Usaremos as rotas da aula de Express. :id representa o identificador do usuário.

usersApi: as operações da API

Cada método representa uma requisição de usuários.

src/services/USerApi.js
import { api } from './api';

export const usersApi = {
  async listUsers() {
    const response = await api.get('/users');
    if (!Array.isArray(response.data)) {
      throw new Error('A listagem da API deve retornar um array de usuários.');
    }
    return response.data;
  },

  async getByID(id) {
    const response = await api.get(`/users/${id}`);
    return response.data;
  },

  async createUser(userData) {
    const response = await api.post('/users', userData);
    return response.data;
  },

  async updateUser(id, userData) {
    const response = await api.put(`/users/${id}`, userData);
    return response.data;
  },

  async deleteUser(id) {
    const response = await api.delete(`/users/${id}`);
    return response.data;
  }
};

Array.isArray confirma o contrato da resposta. response.data é o corpo recebido. Preserve a capitalização USerApi.js usada no import do arquivo anexado.

async e await

A API demora um pouco para responder. A função precisa esperar.

  • async: declara uma função que retorna uma Promise, uma promessa de resultado.
  • await: espera esse resultado para continuar a função. O navegador continua funcionando.
Exemplo para entender: não precisa adicionar ao projeto
async function exemplo() {
  try {
    const dados = await usersApi.listUsers()
    console.log(dados)
  } catch (erro) {
    console.error(erro)
  }
}

Analogia: você faz um pedido e recebe uma senha. await espera o seu pedido ficar pronto. try tenta executar a chamada, catch trata uma falha e finally, quando presente, executa ao finalizar.

GET / 1. Consultar e guardar

A página abre, a API responde e os dados entram no estado.

UsersPage.jsx: dentro da função UsersPage(), antes do return
useEffect(() => {
  async function loadUsers() {
    try {
      const responseUsers = await usersApi.listUsers();
      setUsers(responseUsers);
    } catch (error) {
      setError(getErrorMessage(error));
    } finally {
      setLoading(false);
    }
  }
  loadUsers();
}, []);

loadUsers: é a função async que faz a consulta dentro do efeito. await espera a resposta; setUsers guarda a lista. catch transforma a falha em mensagem e finally encerra o carregamento. []: a consulta acontece ao montar o componente, sem depender de valores reativos. No desenvolvimento com StrictMode, o React pode executar o efeito novamente.

Resultado esperado: Ao terminar a consulta, users contém a lista e loading passa a false.

DELETE / 1. Excluir na API

A função recebe o usuário que a pessoa escolheu excluir.

UsersPage.jsx: dentro de UsersPage(), antes do return
async function handleDelete(user) {
    if (busy || !window.confirm(`Deseja excluir ${user.name}?`)) return
    setBusy(true)
    setError('')
    setNotice('')
    try {
      await usersApi.deleteUser(user.id)
      setUsers((currentUsers) => currentUsers.filter((item) => item.id !== user.id))
      setNotice('Usuário excluído com sucesso.')
    } catch (error) {
      setError(getErrorMessage(error))
    } finally {
      setBusy(false)
    }
  }

confirm: a pessoa decide se deseja continuar. deleteUser(user.id): envia DELETE. filter: cria uma lista sem o registro excluído. setUsers recebe essa nova lista e a tela muda. currentUsers é a lista mais recente. Se a API falhar, o catch mostra o erro.

Resultado esperado: A linha só sai do estado depois que o backend confirma a exclusão.

const query = search.trim().toLocaleLowerCase('pt-BR');
